NYC Parks Inspection Program — Data Analysis & Prediction

EM622-A Decision Making Via Data Analysis Techniques · Python · scikit-learn

A full analysis of NYC's Parks Inspection Program dataset (NYC Open Data), from cleaning through predictive modeling. Covers missing-value analysis, data validation (standardizing seasons, coercing years/visitor counts, filtering valid condition codes), and six exploratory visualizations: condition distribution, year-over-year unacceptable-rate trend (with a visible COVID-19 dip), failure rate by district, seasonal patterns, visitor-count trends, and inspection-volume growth.

Built a Random Forest classifier (benchmarked against a Logistic Regression baseline) to predict whether a park inspection will come back Unacceptable, using district, season, inspection type, year, and visitor count as features — evaluated with ROC-AUC, a confusion matrix, and 5-fold cross-validation, plus a feature-importance breakdown. Inspection year and district turned out to be the strongest predictors of failure, and the Random Forest's higher Recall matters operationally: missing an at-risk park is costlier than a false alarm.

Built with a teammate, Aditya, for Prof. Sang Won Bae's course.
