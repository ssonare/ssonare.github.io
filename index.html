Agentic Paper Trader

View on GitHub →

Capstone project · FastAPI · PostgreSQL · Celery/Redis · Alpaca API

An autonomous paper-trading system: an LLM agent reads live market data and proposes trades, which only execute after passing a deterministic risk-policy engine and human approval. Built around a strict "fail closed" principle — if something can't be verified, the system denies rather than guesses.

My contributions:

  • Idempotent order submission and reconciliation — deterministic client order IDs, duplicate-order prevention, and automatic recovery from timeouts or crashes mid-submit
  • Risk policy implementation (cash reserve enforcement) and cycle-overlap protection for the agent orchestrator
  • Centralized a shared constants module across the backend as a behavior-preserving refactor, with full test coverage proving nothing changed
  • Cross-team code review — caught and verified fixes for a scheduler startup bug, kill-switch enforcement gaps, and a stuck-cycle dead end before they reached production
